# CCDC Reflections
 
The central hub for everything I learn and do while preparing for and competing in the **Collegiate Cyber Defense Competition (CCDC)** as part of the Linux team.
 
Each simulation and competition has its own repository. This repo ties them together and holds the lessons that carry across events.

- **Event index**: links to each simulation and competition repo
- **Playbooks**: reusable step-by-step checklists that apply across events
- **Cheat sheets**: commands and techniques collected over the season
- **Season reflections**: patterns across events, goals, and progress
